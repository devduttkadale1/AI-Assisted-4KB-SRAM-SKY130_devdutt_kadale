Task 5 integrated SRAM timing signoff

Timing method:
  External OpenSTA 3.1.0 STA using the generated OpenRAM Liberty timing model.
  OpenSTA 3.1.0 was built from source and executed successfully; OpenROAD was not required.
  The logical 1024x32 wrapper contains only direct wires and spare tie-offs,
  therefore it adds no RTL logic delay and inherits macro timing constraints.
